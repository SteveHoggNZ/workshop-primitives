## Reference

### Terminology

* https://awesome-copilot.github.com/learning-hub/github-copilot-terminology-glossary/

### Hooks

* https://docs.github.com/en/copilot/reference/hooks-reference (events, configuration and payloads for the Copilot CLI and cloud agent; see "Policy hooks" for machine-wide hooks an admin deploys, which developers can't turn off. Only the CLI reads them)
* https://docs.github.com/en/copilot/reference/copilot-cli-reference/cli-hooks-reference (the CLI's hook events, including `subagentStart` and `subagentStop`)
* https://code.visualstudio.com/docs/agent-customization/hooks (hooks in VS Code, preview)

### Code navigation (LSP)

* https://docs.github.com/en/copilot/concepts/agents/copilot-cli/lsp-servers (what LSP servers give the Copilot CLI)
* https://docs.github.com/en/copilot/how-tos/copilot-cli/set-up-copilot-cli/add-lsp-servers (setup: `~/.copilot/lsp-config.json` or `.github/lsp.json` in the repo; check with `/lsp`)

## Skills

* https://github.com/github/awesome-copilot/tree/main/skills/lsp-setup (installs and configures an LSP server for the Copilot CLI; say "setup LSP")

## Inspiration

* https://skills.sh/ (a directory of agent skills you can install with one command, with leaderboards and security audits)
* https://impeccable.style/ (a design toolkit for coding agents: polish and critique commands, a detector for generic AI-looking design, and keeping new work consistent with your design system)
