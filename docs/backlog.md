# Backlog

Items the team has agreed to build, roughly in order. Each is a starting point for a conversation,
not a spec.

## B1. Due dates and priority

As a user, I want to give tasks a due date and a priority, so I can see what matters first.

- Tasks can have a due date and a priority.
- The task list can be sorted and filtered by them.
- Overdue tasks stand out.
- The API supports the same.

## B2. Tags

As a user, I want to tag tasks and filter by tag, so I can group related work.

## B3. Export

As a user, I want to download my tasks as a CSV file.
